# 4plebs и Архивач

Два парсера для исследовательской работы. [4plebs](4plebs_parser.py) получает посты из поискового JSON API, фильтрует их по стране и сохраняет в CSV. [Архивач](arhivach_parser.py) сначала собирает ссылки на треды из HTML-выдачи, затем разбирает посты в каждом треде и фильтрует их по тексту и датам.

## Установка

Из корня репозитория, с Python 3.10 или новее:

```bash
python -m pip install -r requirements.txt
```

## Архивач без сети

```bash
python arhivach_parser.py --from-html . --query экспедиция \
  --start-date 2021-05-11 --end-date 2021-05-25 --posts-out arhivach_demo.csv
```

Из четырёх постов в [синтетическом HTML](arhivach_example.html) пройдут два, с ID `100` и `101`. Конец диапазона включён. В CSV будут тексты «Экспедиция прибыла на станцию.» и «Экспедиция вернулась.»

Для сетевого запуска убери `--from-html .`. Параметр `--save-html DIR` сохраняет страницы тредов для повторного разбора. Список аргументов выводит `python arhivach_parser.py --help`.

## 4plebs

Настрой запрос, доску и число страниц в начале [скрипта](4plebs_parser.py), затем запусти:

```bash
python 4plebs_parser.py
```

По умолчанию сохраняются только посты с `poster_country == "US"`. Если требуется передать данные своей браузерной сессии, задай в окружении `FOURPLEBS_COOKIE` и `FOURPLEBS_USER_AGENT`.

Таймаут, HTTP-ошибка или неожиданный ответ API останавливают выгрузку с кодом 1. Скрипт заменяет `results.csv` только после успешного обхода запрошенных страниц или достижения конца выдачи. При сбое CSV от предыдущего запуска остаётся на месте.
