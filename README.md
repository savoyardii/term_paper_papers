В курсовой я сравнил, как пользователи 2ch и 4chan реагировали на массовые стрельбы и нападения на учебные заведения. Парсеры понадобились, чтобы найти обсуждения выбранных событий в Архиваче (2ch) и 4plebs (4chan) и собрать тексты постов с привязкой к тредам и временем публикации, где оно было доступно. Из собранных данных я сформировал выборку из 801 поста — 401 с 2ch и 400 с 4chan — и сравнил тональность, эмоции и отношение пользователей к насилию.

# 4plebs и Архивач

Два парсера для исследовательской работы. [4plebs](4plebs_parser.py) получает посты из поискового JSON API, фильтрует их по стране и сохраняет в CSV. [Архивач](arhivach_parser.py) сначала собирает ссылки на треды из HTML-выдачи, затем разбирает посты в каждом треде и фильтрует их по тексту и датам.
